# AURA — պատրաստ запуск Windows-ի համար

AURA-ն արդեն հավաքված է։ Սովորական օգտագործման համար Windows-ում պարզապես կրկնակի սեղմիր **START_AURA.bat**։

Առաջին գործարկման ժամանակ այն ինքնուրույն կտեղադրի անհրաժեշտ npm փաթեթները և կբացի AURA-ն `http://localhost:5173` հասցեով։

AI Core-ը կարող է աշխատել նաև առանց Groq API key-ի՝ տեղային fallback-ով։ Groq-ը միացնելու համար `.env` ֆայլում լրացրու `GROQ_API_KEY`-ը։

Կանգնեցնելու համար փակիր բացված terminal պատուհանը։
